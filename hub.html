Como subir cada coisa

Keycloak (realm techpix)scripts/keycloak-up.sh
OPA + JFrog (políticas e artefatos)docker compose --profile auth up -d opa  ·  scripts/jfrog-up.sh
App com loginSPRING_PROFILES_ACTIVE=secure ./mvnw -pl monolith spring-boot:run
Argo CDTECHPIX_GIT_URL=http://host.docker.internal:3001/techpix/tech-pix.git scripts/argocd-up.sh
Prometheus + Grafanadocker compose --profile observability up -d
Painelpython scripts/painel.py

Os port-forwards (Tekton Dashboard, Argo CD, Kiali) caem quando o terminal fecha — reabra pelos botões do painel. O indicador de status usa fetch dos health endpoints; se o navegador bloquear a checagem a partir de file://, a bolinha fica cinza, mas os links continuam funcionando.
